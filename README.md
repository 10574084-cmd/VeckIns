# veck-inspect

Abre veck.io en un navegador de GitHub, con `veck_steve.user.js` puesto, y guarda lo que ve.

1. Sube estos archivos a un repo nuevo (puede ser privado).
2. Pestaña **Actions** -> **Inspeccionar veck.io** -> **Run workflow**.
3. Cuando termine (3-5 min), abajo en **Artifacts** baja `veck-inspeccion` y mandamelo (zip).
